# 프로젝트 개발 기준

이 프로젝트에서 템플릿·에셋·AI 기능을 추가하거나 수정할 때 다음 기준을 따른다.

1. 화면에 표시되는 모든 디자인 템플릿은 단일 이미지가 아니라 편집 가능한 요소의 집합으로 저장한다.
2. 텍스트·사진·로고·CTA·색상은 역할(role)을 가진 슬롯으로, 배경 장식은 잠금 요소로 구분한다.
3. 텍스트의 렌더링 영역, 선택 상자, 더블클릭 편집 영역은 같은 좌표 계산을 사용한다.
4. 템플릿은 최소한 정사각형·세로형·가로형 파생을 고려하고, 절대 좌표만이 아니라 정렬과 비율 제약을 함께 저장한다.
5. 서비스 화면, 코드의 사용자 문구, 템플릿 이름에 사용 금지된 외부 상표명을 노출하지 않는다.
6. 기존 카드뉴스를 데이터로 쓸 때는 직접 제작했거나 사용·재학습 권한을 확보한 자료만 사용한다. 타사 템플릿의 무단 복제·수집·학습은 금지한다.
7. 이미지뿐인 카드뉴스는 OCR·영역 분석으로 초안을 만들 수 있으나, 텍스트·폰트·레이어·저작권을 사람이 검수한 뒤에만 템플릿 라이브러리에 등록한다.
8. AI 기능은 처음부터 이미지 생성 모델을 미세조정하지 않는다. 구조화 템플릿 검색·추천과 JSON 검증을 우선 구현한다.
9. 기능을 새로 개발하거나 큰 변경을 검토하기 전 `docs/development-baseline.md`를 확인한다. 해당 문서의 목표 구조, 현재 상태, 우선순위와 비교하여 기능의 위치를 기록한다.
10. 검수·승인·반려·최종 잠금·출력 제한 단계는 사용자가 별도 지시하기 전까지 후속 단계로 보류한다.
11. 이 서비스의 기본 경험은 AI 선제 제안이다. 디자인 비전문 사용자가 키워드, 인물 사진, 소속 정당명, 지역, 기호 등 최소 정보를 입력하면 AI가 필요한 추가 질문만 하고 3개 계열의 편집 가능한 시안을 먼저 제안한다. 수동 편집기는 시안 선택 후 보정하는 단계로 설계한다.
12. AI가 생성·수정할 때 후보자명, 소속 정당명, 지역, 기호, 로고 등 사실 정보와 잠금 요소는 임의로 바꾸지 않는다. 입력값과 AI 제안값을 구분해 사용자에게 확인시킨다.
