# 편집 가능한 카드뉴스 템플릿 구축 및 학습 전략 보고서

## 1. 목적

정치 커뮤니케이션용 디자인 서비스에서 사용자가 제목, 본문, 사진, 로고, 색상만 바꾸어도 완성도 있는 카드뉴스를 만들 수 있도록 한다. 템플릿은 한 장의 배경 이미지가 아니라 독립적으로 선택·이동·수정·잠금할 수 있는 요소들의 구조화된 조합으로 제공한다.

## 2. 템플릿의 정의

템플릿 한 장은 캔버스와 요소 목록으로 저장한다. 각 요소에는 위치, 크기, 스타일, 순서, 편집 권한과 역할을 둔다.

```json
{
  "canvas": { "width": 1080, "height": 1080 },
  "elements": [
    { "type": "image", "role": "candidate_photo", "editable": true },
    { "type": "text", "role": "headline", "editable": true, "maxChars": 22 },
    { "type": "text", "role": "body", "editable": true, "maxChars": 100 },
    { "type": "image", "role": "logo", "editable": true },
    { "type": "shape", "role": "background_decoration", "locked": true }
  ]
}
```

`role`은 자동 채우기와 AI 추천의 기준이다. 예를 들어 `headline`, `body`, `candidate_photo`, `logo`, `cta`, `date`, `district`, `background_decoration`을 공통 역할로 사용한다.

## 3. 제작 원칙

- 배경, 장식, 프레임은 잠금 처리한다.
- 제목과 본문은 글자 수, 최소/최대 글자 크기, 줄 수, 줄 간격 제약을 둔다.
- 사진 슬롯에는 권장 비율과 안전 여백을 둔다.
- 주요 디자인은 정사각형(1080×1080), 세로형(1080×1350), 가로형(1920×1080)으로 파생한다.
- 요소의 위치는 절대 좌표와 함께 정렬 기준(좌측·가운데·우측, 상단·중앙·하단) 및 비율 제약을 보관한다.
- 텍스트의 표시 범위, 선택 테두리, 인라인 편집기는 동일한 요소 경계값을 사용한다.

## 4. 우선 제작할 템플릿군

1. 인물·후보 중심 소개형
2. 정책·공약 요약형
3. 수치·그래프 인포그래픽형
4. 공지·일정 안내형
5. 비교표·질문답변형
6. 영상·라이브 예고형
7. 3~5장 연속 카드뉴스 세트형

각 템플릿군은 최소 3종의 레이아웃과 3종의 화면 비율을 제공한다. 초기 목표는 10~20개의 품질 검수 완료 템플릿 세트다.

## 5. 기존 카드뉴스의 템플릿화

### 5.1 편집 원본이 있는 경우

PSD, Figma, Illustrator 등 레이어 원본을 우선 사용한다. 텍스트, 이미지, 도형, 배경을 각각 가져와 요소와 슬롯으로 변환한다. 이 방식이 가장 정확하고 비용이 낮다.

### 5.2 이미지 파일만 있는 경우

1. OCR로 문구와 문구 영역을 추출한다.
2. 이미지·인물·도형·표·배경 영역을 탐지한다.
3. 요소별 위치와 스타일을 포함한 템플릿 초안을 생성한다.
4. 사람이 글자, 폰트, 줄바꿈, 사진 크롭, 잠금 여부를 검수한다.
5. 검수 완료본만 템플릿 라이브러리에 등록한다.

이미지 한 장을 완전 자동으로 편집 가능한 디자인으로 복원하는 방식은 품질이 일정하지 않다. 자동화는 초안 생성까지, 등록은 사람 검수 후에 하는 운영이 필요하다.

## 6. AI 학습 및 추천 전략

처음에는 모델 미세조정보다 검색·추천 방식을 사용한다.

1. 사용 권한이 확인된 카드뉴스와 템플릿을 수집한다.
2. 주제, 레이아웃, 색상, 사진 수, 텍스트 분량, 업종·선거 유형, 분위기, 화면 비율을 메타데이터로 기록한다.
3. 사용자 요청과 메타데이터를 비교해 적합한 템플릿을 추천한다.
4. 선택된 템플릿의 슬롯에 사용자 문구와 사진을 채운다.
5. 글자 수·안전 여백·가독성·오버플로우를 JSON 검증 규칙으로 검사한다.

구조화된 템플릿 데이터가 충분히 축적된 뒤에는 자연어 요청을 템플릿 JSON 초안으로 바꾸는 기능을 도입한다. 생성 결과는 항상 스키마 검증과 편집 화면 검토를 거쳐야 한다.

## 7. 데이터 권리와 운영 원칙

- 직접 제작했거나 계약·라이선스로 사용 및 학습 권한을 확보한 자료만 사용한다.
- 타사 디자인을 화면 참고 수준을 넘어 복제·수집·학습 데이터로 이용하지 않는다.
- 원본 출처, 권리 상태, 제작자, 사용 범위, 승인 일자를 함께 기록한다.
- 인물 사진, 선거 관련 민감 정보, 로고는 별도 사용 권한과 보관 정책을 적용한다.

## 8. 권장 개발 순서

1. 템플릿 제작 모드: 요소 잠금, 슬롯 역할, 글자 수 제한, 안전 영역 지정
2. 템플릿 라이브러리: 카테고리, 미리보기, 검색, 즐겨찾기, 화면 비율 필터
3. 자동 채우기: 후보 정보·문구·사진을 역할별 슬롯에 반영
4. 반응형 파생: 같은 템플릿을 정사각형·세로·가로 규격으로 변환
5. 자료 등록 파이프라인: 권리 확인, OCR/영역 분석, 검수, 승인, 버전 관리
6. AI 추천과 JSON 초안 생성

## 9. 완료 기준

- 각 템플릿의 모든 수정 대상이 독립 요소로 선택·편집된다.
- 잠금 요소는 일반 편집 중 이동·삭제되지 않는다.
- 텍스트는 입력, 선택, 렌더링 시 같은 영역에 표시된다.
- 화면 비율 변경 후에도 제목, 사진, CTA가 안전 영역을 벗어나지 않는다.
- 템플릿과 학습 데이터의 권리 상태를 추적할 수 있다.
