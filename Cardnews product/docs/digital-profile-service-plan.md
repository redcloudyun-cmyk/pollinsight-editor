# 디지털 명함·프로필 페이지 서비스 기획서

작성일: 2026-07-27  
상태: 1차 구현 기준

## 1. 목표

디자인 도구에 익숙하지 않은 사용자가 템플릿을 선택하고 기본 정보만 입력해,
모바일에 최적화된 개인 소개·포트폴리오 페이지를 발행할 수 있게 한다. 이 서비스는
기존 디자인 편집·AI 제안·프로젝트·회원·관리 기능을 재사용하는 별도 유료 상품이다.

정치 캠페인 사용자에게는 후보자 소개, 공약, 활동 자료, 문의 채널을 한 주소에
정리하는 프로필 페이지로 제공한다. 일반 사용자는 프리랜서, 디자이너, 지역 활동가,
소상공인 등의 명함·포트폴리오 페이지로 사용한다.

## 2. 사용자 흐름

1. 내 작업에서 `디지털 명함 만들기`를 선택한다.
2. 인물형, 포트폴리오형, 캠페인형 중 템플릿을 고른다.
3. 이름, 역할/직책, 소개, 사진, 연락처, 링크, 프로젝트·자료를 입력한다.
4. AI 제안 기능은 소개 문구와 섹션 순서를 제안하며, 사용자가 최종 선택한다.
5. 모바일 미리보기에서 확인 후 비공개 저장 또는 공개 발행한다.
6. 발행된 주소와 QR 코드를 공유하고, 방문·링크 클릭·문의 현황을 마이페이지에서 본다.

## 3. 1차 기능 범위

### 제작

- 완성형 템플릿 3종: 인물 소개, 포트폴리오, 캠페인/지역 활동
- 프로필 사진, 이름, 역할, 소개 문구, 강조 문구
- 전화, 이메일, 메신저, 외부 링크
- 포트폴리오·자료실·문의 버튼 섹션
- 모바일 우선 미리보기와 공개/비공개 상태
- 사용자가 수정 가능한 짧은 공개 주소(slug)와 QR 이미지

### 운영

- 회원별 프로필 페이지 목록 및 상태
- 관리자 대시보드의 발행 수, 공개 수, 방문 수, 링크 클릭 수
- 공개 페이지의 조회 및 링크 클릭 이벤트 기록
- 관리자에 의한 비공개 전환과 공개 주소 변경 관리

### 요금 및 권한 원칙

| 구분 | 무료 | 명함 플랜 | 프로 플랜 |
| --- | --- | --- | --- |
| 공개 페이지 | 1개 | 3개 | 10개 이상 |
| 템플릿 | 기본 | 전체 | 전체·맞춤 |
| 포트폴리오/자료 | 제한 | 확장 | 확장 |
| QR/통계 | 기본 QR | 방문·클릭 통계 | 고급 통계·도메인 연결 |
| AI 문구 제안 | 체험 | 월별 한도 | 높은 한도 |

실제 금액, PG 결제, 신용카드 정기결제는 별도 결제 정책 확정 후 연결한다. 1차 구현은
플랜 자격을 `free / basic / premium` 회원 등급에 매핑하되, 별도 상품 플래그를
추가할 수 있는 구조로 둔다.

## 4. 데이터 모델

`digital_profiles`

- 소유자(user_id), 제목, slug, 템플릿 키, 공개 상태
- 프로필 데이터(JSON): 기본 정보, 링크, 포트폴리오, 자료
- 발행 시각, 갱신 시각

`digital_profile_events`

- profile_id, event_type(view / link_click / inquiry), 대상 링크, 발생 시각
- IP 등 개인식별 정보는 1차 범위에서 저장하지 않는다.

## 5. 공개와 안전 기준

- 공개 페이지는 slug만으로 조회하되, 비공개 페이지는 404로 처리한다.
- 모든 입력 텍스트는 HTML로 해석하지 않고 이스케이프해 렌더링한다.
- 전화·이메일·외부 URL은 사용자가 입력한 값만 사용하고, 링크는 안전한 프로토콜만 허용한다.
- 자료 업로드, 맞춤 도메인, 문의 수신 알림은 후속 단계로 분리한다.

## 6. 기존 솔루션 연결 기준

- 편집기에서 만든 카드뉴스는 포트폴리오 항목의 대표 이미지 또는 외부 콘텐츠 링크로 연결한다.
- 기존 템플릿 제작 관리와는 분리해, 명함 페이지 템플릿은 웹 섹션 구조를 관리한다.
- 마이페이지의 사용량 영역에 공개 페이지 수와 이번 달 방문·클릭 수를 추가한다.
- 관리자 대시보드는 회원별 사용량을 기존 AI·편집·크레딧 지표와 함께 보여 준다.

## 7. 단계별 구현

1. **현재 단계**: 프로필 생성·수정·공개/비공개·공개 URL·QR·조회/클릭 기록·내 목록.
2. 템플릿 관리자, 포트폴리오 이미지/자료 업로드, 디자인 편집기 콘텐츠 연결.
3. AI 소개·섹션 제안, 문의 수집함, 상세 분석.
4. 별도 상품 결제, 맞춤 도메인, 팀 공동 관리.

## 8. 이번 구현의 완료 조건

- 로그인 사용자가 프로필을 생성하고 공개 상태를 전환할 수 있다.
- 공개 상태의 주소는 로그인 없이 모바일 화면에서 열 수 있다.
- 공개 페이지 방문과 링크 클릭이 집계된다.
- 개인 화면에서 본인 프로필 상태와 기본 통계를 확인한다.
- 실제 결제 연동이나 맞춤 도메인 기능은 구현 완료로 표시하지 않는다.
