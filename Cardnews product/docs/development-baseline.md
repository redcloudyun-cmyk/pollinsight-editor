# 개발 기준선: AI 기반 정치 커뮤니케이션 디자인 플랫폼

## 사용 목적

이 문서는 기획안과 현재 구현 상태를 비교하는 기준선이다. 기능 개발, 설계 검토, 우선순위 조정 때마다 이 문서를 확인한다. 완료된 기능은 상태를 갱신하고, 새 기능은 어느 목표 항목을 충족하는지 기록한다.

## 제품의 목표 흐름

`최소 입력 → AI 보완 질문 → 의미 판단 → Ruleset 선택 → 제약 기반 배치 → 3계열 시안 → 사용자 편집·출력`

- 최소 입력: 디자인 비전문 사용자가 키워드, 인물 사진, 소속 정당명, 지역, 기호 등만 입력한다.
- AI 보완 질문: AI는 슬로건, 공약, 대상, 어조, 카드 수처럼 결과 품질에 꼭 필요한 정보만 대화형으로 질문한다. 사용자가 슬로건을 모르면 후보 문구와 근거를 먼저 제안한다.
- 의미 판단: 카피의 핵심어, 어조, 정보 밀도, 카드 역할을 구조화한다.
- Ruleset 선택: 템플릿의 요소 역할, 안전 영역, 사진 영역, 텍스트 제약, 로고 앵커를 선택한다.
- 제약 기반 배치: 글자 수, 사진 비율, 안전 영역, 요소 충돌, 가독성을 계산해 배치한다.
- 3계열 시안: 인물 중심형, 텍스트·그래픽 중심형, 포스터·감성형을 생성한다.
- 사용자 편집·출력: 사용자가 최종 편집하고 결과물을 저장·내보낸다.

## 핵심 사용자 경험 원칙

- 이 서비스의 차별점은 사용자가 빈 캔버스에서 디자인을 시작하지 않고, AI가 먼저 세 가지 서로 다른 방향의 시안을 제안하는 데 있다.
- 기본 결과는 인물 중심형, 텍스트·그래픽 중심형, 포스터·감성형의 세 계열이다. 단순 색상 변경이 아니라 정보 구조와 시각적 중심이 달라야 한다.
- 사용자는 시안 선택 후 제목·사진·문구·색상만 보정할 수 있어야 한다. 전문 디자인 도구 경험을 전제하지 않는다.
- 후보자명, 소속 정당명, 지역, 기호, 로고 같은 사실 정보는 입력값으로 관리하고 AI가 추측하거나 변경하지 않는다.
- AI가 질문한 항목, 사용자가 확정한 정보, AI가 제안한 문구를 구분해 표시한다.

## 우선 개발 순서

1. 공용 템플릿 라이브러리: 회원 편집기에서 분류·해시태그로 템플릿을 검색·선택·불러오기
2. Ruleset 구조: 카드 역할, 사진 영역, 텍스트 영역, 로고 앵커, 안전 영역, 잠금 규칙, 글자 수 제약 저장
3. AI 선제 제안 마법사: 키워드·인물 사진·소속 정당명·지역·기호 입력, 필요한 보완 질문, 슬로건 제안과 확정
4. 제약 기반 자동 배치: 텍스트·이미지·안전 영역·가독성 제약을 검증
5. 3계열 시안 생성: 인물 중심형 / 정보 중심형 / 감성형의 편집 가능한 결과 생성
6. 카드뉴스 분석 파이프라인: 권리 확인 → OCR·영역 분석 → 검수 → Ruleset 등록
7. 조직·프로젝트 권한, 변경 이력, 버전 복원
8. 승인 워크플로: 별도 지시 시 시작

## 품질 게이트

- 템플릿은 단일 이미지가 아니라 독립 요소와 역할 슬롯으로 저장한다.
- 텍스트 렌더링, 선택 테두리, 인라인 편집 영역은 같은 좌표를 사용한다.
- 자동 배치 결과는 글자 오버플로우, 요소 충돌, 안전 영역 위반을 검사한다.
- 템플릿·학습 데이터는 사용·재학습 권한이 확인된 자료만 사용한다.
- 미리보기와 최종 출력은 동일한 레이아웃 데이터를 사용한다.
- AI 모델 연결은 특정 공급자에 고정하지 않고 교체 가능한 서비스 경계로 분리한다.
